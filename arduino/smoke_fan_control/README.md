# MQ-2 煙霧偵測 → 繼電器 → 風扇 自動控制

用 **MQ-2 煙霧/可燃氣體感測器** 偵測煙味，超過門檻時透過**繼電器**啟動**風扇**排煙；
煙味消散並維持一段時間後自動關閉。

## 需要的零件

| 零件 | 說明 |
|------|------|
| Arduino Uno（或相容板） | 主控板 |
| MQ-2 煙霧感測器模組 | 要用到 **A0（類比輸出）** 腳 |
| 1 路繼電器模組 | 預設為**低電平觸發**（IN=LOW 時開）|
| 風扇 | 由**獨立電源**供電，串在繼電器上 |
| 蜂鳴器（選配）| 煙霧超標時警示 |
| 杜邦線若干 | 接線用 |

## 接線

**訊號/電源（接 Arduino）**

| 模組腳位 | 接到 Arduino |
|----------|--------------|
| MQ-2 `VCC` | `5V` |
| MQ-2 `GND` | `GND` |
| MQ-2 `A0`  | `A0` |
| 繼電器 `VCC` | `5V` |
| 繼電器 `GND` | `GND` |
| 繼電器 `IN`  | `D8` |
| 蜂鳴器 `+`（選配）| `D9` |
| 蜂鳴器 `-`（選配）| `GND` |

**風扇電源（走繼電器，不接 Arduino）**

```
風扇電源 +  ──►  繼電器 COM
繼電器 NO   ──►  風扇 +
風扇電源 -  ──────────────►  風扇 -
```

> ⚠️ **安全第一**：若風扇是市電（110V/220V），接線務必斷電、做好絕緣，
> 不熟悉強電請找有經驗的人協助。繼電器的 COM/NO/NC 走的是風扇電源，**絕對不要**接到 Arduino 的腳位。

## 上傳與調校

1. 用 Arduino IDE 開啟 `smoke_fan_control.ino`，選對板子與序列埠後上傳。
2. 打開**序列埠監控器（Serial Monitor）**，鮑率設 **9600**。
3. 等待暖機（預設 20 秒，正式使用建議更久）。
4. 觀察「乾淨空氣」時的煙霧值，再依實際情況調整程式最上方的門檻：
   - `SMOKE_THRESHOLD_ON`：超過就開風扇。
   - `SMOKE_THRESHOLD_OFF`：低於就算安全（做遲滯，避免臨界值反覆開關）。
   - `FAN_KEEP_ON_MS`：煙散後還要多排風多久才關。

## 依你的硬體調整

- **繼電器是高電平觸發？** 把程式裡的 `RELAY_ON` 改成 `HIGH`、`RELAY_OFF` 改成 `LOW`。
- **換別的腳位？** 改 `RELAY_PIN`、`MQ2_ANALOG_PIN`、`BUZZER_PIN`。
- **用 ESP32/Nano？** 注意 ESP32 類比腳與電壓是 3.3V，MQ-2 建議用 5V 供電、
  A0 經分壓後再接，門檻數值也要重新量測。
- **不要蜂鳴器？** 不接 D9 即可，程式會照常運作。

## 運作邏輯

```
讀煙霧值 (0~1023)
   │
   ├─ ≥ ON 門檻  → 記錄時間、開風扇（+蜂鳴器）
   │
   └─ ≤ OFF 門檻 且 距最後一次偵測到煙 ≥ 保持時間 → 關風扇
```

中間的過渡區（OFF~ON 之間）維持現狀，這種**遲滯（hysteresis）**設計可避免
數值在門檻附近抖動時風扇一直開開關關。
