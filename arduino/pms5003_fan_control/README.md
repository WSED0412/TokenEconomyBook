# PMS5003 PM2.5 偵測 → 繼電器 → 風扇 自動控制（抓抽菸煙味）

用 **PMS5003 雷射 PM2.5 感測器**偵測抽菸的煙（煙的本質是懸浮微粒 PM2.5），
超過門檻時透過**繼電器**啟動**風扇**排煙；空氣恢復乾淨並維持一段時間後自動關閉。

> 為什麼不用 MQ-2？MQ 系列量的是「氣體」，抓香菸煙不夠靈敏也容易誤判；
> PMS5003 直接量「微粒」，最對口。

## 需要的零件

| 零件 | 說明 |
|------|------|
| Arduino Uno（或相容板） | 主控板 |
| PMS5003 PM2.5 感測器 | UART 數位輸出，附 8-pin 轉接線最方便 |
| 1 路繼電器模組 | 預設**低電平觸發**（IN=LOW 時開）|
| 風扇 | 由**獨立電源**供電，串在繼電器上 |
| 蜂鳴器（選配）| 超標時警示 |
| 杜邦線若干 | 接線用 |

## 接線

**訊號/電源（接 Arduino）**

PMS5003 用 5V 供電，資料是 UART。我們只需要「讀」它的資料，所以只接它的 **TX**。

| PMS5003 腳位 | 接到 Arduino | 說明 |
|--------------|--------------|------|
| `VCC`（PIN1）| `5V` | 供電 |
| `GND`（PIN2）| `GND` | 共地 |
| `TX`（PIN5） | `D10` | PMS 的 TX → Arduino 的接收腳（SoftwareSerial RX）|
| `RX`（PIN4） | 不接 | 本程式沒有對 PMS 下指令，可不接 |
| `SET` / `RESET` | 不接 | 讓它保持預設（一直運作）即可 |

| 其他模組 | 接到 Arduino |
|----------|--------------|
| 繼電器 `VCC` / `GND` / `IN` | `5V` / `GND` / `D8` |
| 蜂鳴器 `+` / `-`（選配）| `D9` / `GND` |

> PMS5003 的 TX 是 3.3V 邏輯，Arduino Uno 讀得到、沒問題。
> 它的 VCC 要用 **5V**（內部風扇要 5V 才轉得動）。

**風扇電源（走繼電器，不接 Arduino）**

```
風扇電源 +  ──►  繼電器 COM
繼電器 NO   ──►  風扇 +
風扇電源 -  ──────────────►  風扇 -
```

> ⚠️ **安全第一**：若風扇是市電（110V/220V），接線務必斷電、做好絕緣。
> 繼電器的 COM/NO/NC 走的是風扇電源，**絕對不要**接到 Arduino 腳位。

## 上傳與調校

1. 用 Arduino IDE 開啟 `pms5003_fan_control.ino`，選對板子與序列埠後上傳。
2. 打開**序列埠監控器（Serial Monitor）**，鮑率 **9600**。
3. 等待啟動穩定（預設 30 秒，PMS5003 內部風扇/雷射需要暖身）。
4. 觀察平常的 PM2.5 數值，再依環境調整程式最上方的門檻：
   - `PM25_THRESHOLD_ON`：超過就開風扇（預設 50 µg/m³）。
   - `PM25_THRESHOLD_OFF`：低於就算乾淨（預設 25，做遲滯避免反覆開關）。
   - `FAN_KEEP_ON_MS`：超標後還要多排風多久才關（預設 15 秒）。

**PM2.5 數值參考**：良好室內通常 < 15；有人抽菸時常飆到數十甚至上百。
如果誤觸或太遲鈍，就微調 `PM25_THRESHOLD_ON`。

## 依你的硬體調整

- **繼電器是高電平觸發？** 把 `RELAY_ON` 改成 `HIGH`、`RELAY_OFF` 改成 `LOW`。
- **換別的腳位？** 改 `PMS_RX_PIN`、`RELAY_PIN`、`BUZZER_PIN`。
- **用 ESP32/Mega？** 它們有多組硬體 UART，可以不用 SoftwareSerial，
  直接接 `Serial1`/`Serial2` 會更穩，跟我說我幫你改。
- **不要蜂鳴器？** 不接 D9 即可，程式照常運作。

## 運作邏輯

```
每秒讀一筆 PMS5003 資料 → 取出 PM2.5 (µg/m³)
   │
   ├─ ≥ ON 門檻(50)  → 記錄時間、開風扇（+蜂鳴器）
   │
   └─ ≤ OFF 門檻(25) 且 距最後一次超標 ≥ 保持時間(15s) → 關風扇
```

中間過渡區維持現狀，這種**遲滯（hysteresis）+ 延時**設計可避免數值在門檻附近
抖動時風扇一直開開關關。

## 想更防誤判？

之後可再加一顆 **MQ-135**（氣體/VOC），改成「**PM2.5 飆高 _而且_ 氣體也上升**」
才判定是菸味，能進一步排除「濕度高」「單純有味道」造成的假警報。需要時我可以幫你寫雙感測器版。
